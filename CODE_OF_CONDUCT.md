# Code of Conduct

We want this project to be a welcoming, technically rigorous place to collaborate.

## Expected behavior

Contributors should:

- Be respectful and constructive.
- Critique ideas and code, not people.
- Give actionable review feedback.
- Assume good intent while asking for evidence.
- Respect different experience levels.
- Keep technical discussions focused on the project.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, doxxing, spam, or
deliberate disruption are not tolerated.

## Enforcement

Maintainers may edit, hide, lock, or remove content and may restrict
participation when necessary to protect the community.

Security vulnerabilities should be reported using the process in SECURITY.md
rather than discussed publicly.
